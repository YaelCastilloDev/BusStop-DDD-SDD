# React Routing

Use **TanStack Router** (file-based, code-split). React Router is **not used** in this project.

## Route Files
- File-based: route path maps to file structure. `routes/index.tsx` → `/`, `routes/login.tsx` → `/login`.
- Generated route tree at `src/routeTree.gen.ts` (auto-generated by `@tanstack/router-plugin`).
- Each route file exports `Route` via `createFileRoute`:

```tsx
// routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'
import { MapPage } from '@/features/map/map-page'

export const Route = createFileRoute('/')({
  component: MapPage,
})
```

## Root Route
```tsx
// routes/__root.tsx
import { createRootRouteWithContext, Outlet, Link } from '@tanstack/react-router'
import type { QueryClient } from '@tanstack/react-query'

export const Route = createRootRouteWithContext<{
  queryClient: QueryClient
}>()({
  component: RootComponent,
  notFoundComponent: NotFound,
  errorComponent: ErrorFallback,
})

function RootComponent() {
  return <Outlet />
}
```

- `createRootRouteWithContext` passes `queryClient` (and other context) to all routes.
- `notFoundComponent` and `errorComponent` are native TanStack Router error boundaries — **no external error boundary library needed**.

## Navigation
- `useNavigate()` from `@tanstack/react-router`.
- `<Link to='/'>` for declarative navigation.
- `router.navigate({ to, search, params })` for imperative.

## Route Guards
- `beforeLoad` for auth checks:
```tsx
export const Route = createFileRoute('/admin')({
  beforeLoad: ({ context }) => {
    // check auth via context
  },
  component: AdminPage,
})
```

## Code Splitting
- Enabled via `autoCodeSplitting: true` in vite config.
- `defaultPreload: 'intent'` and `defaultPreloadStaleTime: 0` on router.

## Conventions
- One component per route file. Thin routes — delegate to `@/features/` components.
- Route paths are flat: `routes/login.tsx` → `/login`, not nested unless needed.
- `@/` alias for `src/` directory imports.
